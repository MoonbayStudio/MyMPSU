# Безопасность и секреты

## Что нельзя коммитить

- `.env` и любые реальные файлы окружения;
- JWT/SMTP/OAuth секреты, пароли БД и приватные API-ключи;
- `GoogleService-Info.plist`, `google-services.json`, ключи подписи и provisioning profiles;
- дампы базы, локальные кэши и токены пользователей;
- приватный ключ подписи Tauri updater.

В репозитории хранятся только файлы `*.env.example` с безопасными заглушками.
Значения с префиксом `VITE_` попадают в frontend bundle и поэтому **никогда не
должны быть секретами**. В `Desktop/.env` допустимы только публичные URL и
переключатели.

Desktop-токен авторизации сохраняется нативной частью Tauri в системном
хранилище учётных данных: Keychain на macOS, Credential Manager на Windows и
Secret Service на Linux. Публичные настройки и кэш расписания хранятся отдельно
и не содержат токена.

Перед публикацией выполните:

```bash
./scripts/check-secrets.sh
git status --short
git diff --cached
```

Если секрет когда-либо попал в коммит, одного удаления из текущего файла
недостаточно: сначала отзовите/перевыпустите секрет, затем очистите историю
Git и форки согласно правилам хостинга.
